# 저장소 계보와 공개 범위

`naia-pj-adk`는 여러 참여자가 같은 프로젝트 규칙을 적용하도록 만든 독립적인 팀
어댑터 저장소입니다. 개인 작업환경을 관리하는 ADK와 연결될 수 있지만, 개인 설정,
운영 기록, 참가자 등록부, 제품 소스, 그 저장소의 Git 이력을 포함하지 않습니다.

이 후보에서 채택한 것은 이슈 중심 작업, 역할 기반 권한, 선언형 통합 브랜치,
기계 검증 계약, 실패 시 닫히는 배포·알림 게이트처럼 여러 프로젝트에 적용할 수
있는 원칙입니다. `projects/example/`은 이 원칙을 보여 주는 비활성 placeholder이며
실제 서비스나 운영 환경을 가리키지 않습니다.

이 문서의 후보는 원격 저장소의 기존 main에서 작업한 독립 작업 트리로 만들었고,
기존 reachable history를 다시 쓰지 않았습니다. 후보의 정확한 기준·변경·검증 SHA는
공개 감사 기록에서 확인하며, SHA를 문서에 고정해 stale한 상태를 만들지 않습니다.

원격 push, visibility 변경, 책·게시물 공개는 소유자의 tree·history·권리 검수와
정확한 후보 SHA 승인 뒤에 별도 실행합니다.
