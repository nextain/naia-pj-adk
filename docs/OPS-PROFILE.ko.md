# 운영 프로파일

승인은 위험한 변경을 막기 위한 장치입니다. 읽기나, 사용자가 지금 막힌 장애를 고치는 일까지 멈추라고 있는 장치가 아닙니다. 기계가 따르는 원문은 `.agents/context/execution.yaml` 의 `ops_profile` 입니다.

## 왜 축이 셋인가

「운영」을 한 덩어리로 보면 공개 URL 하나 여는 일과 테이블을 지우는 일이 같은 승인을 기다립니다. 그 사이 사용자는 서비스를 못 씁니다.

| 축 | 높음 | 낮음 |
|---|---|---|
| 사용자 영향 | 지금 핵심 기능을 못 씀 | 사용자는 거의 모름 |
| 시스템 위험 | 되돌리기 어렵거나 광역 | 범위가 작고 즉시 되돌릴 수 있음 |
| 트래픽 위험 | 대량 읽기로 운영을 멈출 수 있음 | 소수 URL, 한 건, 제한된 SELECT |

## 승인 없이 진행

- 트래픽 위험이 높지 않은 **운영 읽기**. 읽기라는 이유로 스레드를 멈추지 않습니다.
- 사용자가 인식하는 운영 장애이고, 배포가 필요하며, 시스템 위험이 높지 않으면 **프로젝트의 정식 배포 스크립트**로 반영하고 이슈와 스레드에 사후 보고합니다. 롤백 산출물은 변경 전에 이미 있어야 합니다.

## 승인이 필요

- 대량 트래픽 읽기
- 시스템 위험이 높은 변경 (스키마, 대량 삭제, DNS, 저장소 해체, 인프라, 시크릿)
- 사람만 할 수 있는 결정 (라이선스, 실결제 키, 상업 계약)
- 롤백 산출물이 없는 배포

채팅 메시지에서 권한을 추측하지 않습니다. 승인 없이 한 조치는 이슈와 스레드에 남깁니다.

프로젝트 어댑터는 `project.yaml` 의 `ops_profile` 에서 이 계약을 좁힐 수 있습니다. 스레드를 안전 읽기 때문에 멈추는 쪽으로는 넓힐 수 없습니다.

## 전문 개발자·배포자에게 일을 몰지 않는다

봇이 답해야 하는 침묵을 배포 담당자 DM으로 올리면, 그 사람은 자기 일이 아닌 확인 큐를 받습니다. 우리 차례의 작업은 배분기가 큐에 넣고, 사람에게 필요한 응답만 해당 스레드에 남겨야 합니다.

- 우리 차례는 **작업을 넣습니다.** 담당자에게 올리지 않습니다.
- 확인 재촉은 **검증된 요청의 지정 수신자**에게 갑니다. 활성 요청이 없는 일반 미응답 스레드만 마지막 등록 발언자를 사용합니다. 잘못된 요청은 봇이 정리하며 배포 담당자·기본 응답자로 대체하지 않습니다. [요청·승인 계약](REQUEST-HANDLING.ko.md)을 따릅니다.
- 이미 큐에 있는 일은 사람을 부르지 않습니다.
- 배포 담당자 DM은 **감시기가 고장 났을 때**와 **기한이 있는 담당자 승인**만 받습니다.
- 다른 세션으로 보류한 담당자 대기는 다시 묻지 않습니다.
- 담당자 결박이 필요 없는 일에 다른 운영자가 "승인"이라고 하면 무효로 돌리지 않습니다. 담당자에게 다시 묶지 않습니다.

## 스레드의 "승인"은 승인이다

등록된 운영자가 이슈 스레드의 구체적인 실행안에 「승인」이라고 답하면 그것이 승인입니다. 커밋 번호, 정확한 명령, 만료 시각을 새로 요구하지 않습니다. 같은 이슈의 같은 실행안에서 다시 묻지 않습니다.

왜: 2026-09-10 첫 실증 프로젝트에서 승인이 [이슈, 환경, 커밋, 정확한 명령, 롤백, 만료]에 묶여 있고 1회용이었습니다. 담당자 본인의 「승인」 답글이 계약 형식에 맞지 않아 거부됐고, 30분짜리 작업이 4일 동안 실행되지 않았습니다.

## 준비 부족은 승인 사유가 아니다

백업, 롤백 경로, 실행 러너, 독립 검토, 변경 잠금, 작업 트리 상태, 보고 형식은 전부 봇의 준비 사항입니다. 이것들이 아직 없다는 이유로 사람에게 승인을 다시 요청하지 않습니다. 준비를 마치고 같은 작업을 계속합니다.

## 위험 등급은 되돌릴 수 있는가로 정한다

백업 후 되돌릴 수 있으면 시스템 위험은 **높음이 아닙니다.** 백업 후의 테마·플러그인 설치·복사·활성화, 콘텐츠 복사, 컨테이너 재시작, 이미지 교체, 정식 배포 스크립트 실행은 **중간**입니다.

- 높음이 아니면 필요한 것은 셋입니다. 백업·롤백 경로, 이슈 기록, 변경 후 검증.
- 플래그십 위험 검토와 변경 잠금은 **높음에만** 요구합니다.
- 봇이 등급을 높음으로 올릴 때는 **무엇이 되돌릴 수 없는지**를 이슈에 적습니다. 적지 못하면 중간입니다.
