# 표준 구성 선별 적용

## 채택

- 저장소 진입점과 프로젝트별 컨텍스트 분리
- GitHub 이슈 중심의 상태·증거 관리
- 역할과 실행 권한의 명시적 분리
- 실패 시 닫히는 배포·공개·중복 게이트웨이 정책
- 기계 검증 가능한 YAML 계약과 CI
- 프로젝트 어댑터 템플릿
- 검수 후보의 커밋 SHA 고정

## 제외

- 개인 기억·비서·페르소나 중심 기능
- 특정 제품의 과거 요구사항과 진행 기록
- 특정 PC, 서버, 계정, IP, 토큰 정보
- 급여·특허·홍보 등 프로젝트 개발과 무관한 업무 스킬
- 벤치마크 제품과 메신저 실험 구현
- 다른 저장소의 Git 이력

## 연결 방향

`naia-adk`는 사람의 장기 작업환경을, `naia-pj-adk`는 팀 프로젝트의 공동 규칙과 권한을 담당합니다. 양쪽을 합치지 않고, 참여자 등록과 작업 전달을 위한 명시적 어댑터로 연결합니다. `onmam-dev`에서 먼저 실증하고 일반화된 부분만 이 저장소에 반영합니다.
