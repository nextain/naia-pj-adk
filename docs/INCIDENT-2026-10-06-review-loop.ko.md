# 2026-10-06 지시서 검수 반복 사건

10/6 밤 세 갈래의 작업에서 지시서 검수가 각각 7회, 4회, 9회 넘게 돌았고 구현 시작이 1시간 넘게 밀렸다. 회차마다 지적이 하나씩 새로 나오는 양상이었고, 4~5회차 지적은 수정 허용 목록에 헬퍼 이름이 빠졌다는 형식 문제였다. 같은 날 낮에도 검수 7회차로 반나절의 DEV 공백이 있었다.

원인은 네 가지였다. 조정자가 기록 시각만 보고 진전은 보지 않았다. FAIL 원문을 6회차에야 읽었다. 설계가 필요한 항목을 설계 없이 구현 지시서로 넘겨 지시서 검수가 설계를 대신했다. 검수 횟수에 상한이 없어 멈출 판단이 구조에 없었다.

규칙은 `.agents/context/development-method.yaml` 의 `review_orchestration_caps` 에 있고, 횟수 상한은 alpha-adk 의 `.agents/scripts/review-run.mjs` 가 막는다.
