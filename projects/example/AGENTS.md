# Example project adapter

This is a public, disabled example used by the contract tests. Copy it before
activating a project adapter, replace every placeholder with project-owned
values, and keep runtime identities and credentials in ignored files.

Use a GitHub issue and an issue branch for every change. The adapter's
`team_policy` is the source for issue authority, work hours, approval gates,
and assignment routing. A chat message or tool access never grants merge,
deployment, database, or secret authority.
