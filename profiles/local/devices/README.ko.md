# 기기 등록부

회차에 참여하는 실행 자원을 한 파일에 하나씩 적습니다. 기기는 권한의 주체가
아니라 실행자가 서 있는 자리입니다. 파일 이름이 기기 ID이고,
`scripts/qa-round.mjs`가 `platform`을 읽어 그 기기가 가져갈 수 있는 묶음을
고릅니다.

필수 항목은 `id`, `platform`, `owner` 셋입니다. `platform`은 `linux`, `windows`,
`macos` 중 하나이고 `owner`는 GitHub 핸들입니다. 주소와 자격 정보는 적지
않습니다. 호스트 이름은 적어도 되지만 IP는 적지 않습니다.

`_example.yaml`은 모양을 보여 주는 파일입니다. 인스턴스는 이 디렉터리를 자기
저장소의 `devices/`로 복사한 뒤 실제 기기 파일을 추가하고 예시 파일은 지웁니다.
