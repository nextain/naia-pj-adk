# 인계 기록

세션이나 기기를 넘어 일을 잇는 문서를 `YYYYMMDD-<주제>.md`로 둡니다. 상태, 남은
일, 실제 경로와 정확한 SHA, 다음 소유자를 반드시 적습니다.

크로스머신 문서에 "로컬"이라는 상대어를 쓰지 않습니다. 읽는 사람의 기기가 쓴
사람의 기기와 다르면 그 말은 다른 곳을 가리킵니다. 기기 ID와 절대 경로로
적습니다.

인계 문서는 권한을 주지 않습니다. 회차의 실행 상태는 인계 문서가 아니라
`qa/rounds/<회차>/`의 claim과 영수증에서 읽습니다. 문서의 갱신 시각이 새롭다고
내용이 최신인 것은 아닙니다.
